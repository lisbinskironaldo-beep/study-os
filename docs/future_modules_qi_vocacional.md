## 3. Modulo futuro - Teste seu QI

### 3.1 Missao

Criar um teste de QI gamificado, prazeroso e visualmente satisfatorio, baseado em desafios curtos e variados, com leitura de resultado forte no final.

Nao deve parecer:

- prova escolar
- formulario seco
- quiz barato

Deve parecer:

- laboratorio mental
- sequencia de desafios elegantes
- experiencia recompensadora e curiosa

### 3.2 Estrutura do produto

Fluxo principal:

1. entrada do modulo
2. introducao curta com promessa e clima visual
3. sequencia de telas, cada uma com um desafio diferente
4. tela de processamento de resultado
5. tela final com leitura do perfil cognitivo
6. CTA premium para `Turbinar QI`

### 3.3 Tipos de desafio recomendados

O modulo deve combinar tipos diferentes para nao ficar monotono:

- padroes visuais
- sequencias logicas
- memoria curta
- velocidade de percepcao
- rotacao mental
- analogias
- classificacao
- foco seletivo

### 3.4 Regra de tela

Cada desafio deve ocupar uma tela propria.

Cada tela deve ter:

- um objetivo claro
- um estimulo visual principal
- uma acao principal
- progresso visivel
- satisfacao imediata ao concluir

Nao deve ter:

- muito texto explicativo
- painel poluido
- varios caminhos competindo

### 3.5 Linguagem visual

Direcao:

- gamificado com maturidade
- prazer visual sem infantilizacao
- sensacao de laboratorio mental premium
- feedback rapido e limpo

Recursos desejados:

- barras de progresso vivas
- preenchimentos elegantes
- transicoes curtas
- glow discreto
- desafios com contraste alto
- respostas com confirmacao forte

### 3.6 Resultado final

Ao final, o sistema deve entregar:

- pontuacao geral
- leitura das areas mais fortes
- leitura das areas mais fracas
- resumo de desempenho cognitivo
- orientacao de proximo passo

Exemplos de eixos:

- logica
- memoria
- velocidade
- atencao
- padrao visual
- flexibilidade mental

### 3.7 Ponte para premium

Depois do resultado, abre a frente premium:

`Turbinar QI`

Essa frente deve ser apresentada como um laboratorio pessoal para desenvolver o cerebro com base no resultado individual.

### 3.8 Produto premium futuro - Turbinar QI

Missao:

transformar o resultado do teste em um plano de treino cognitivo pessoal

O premium deve entregar:

- trilhas por perfil
- exercicios direcionados por fraqueza
- ciclos de memoria
- treino de atencao
- treino de velocidade mental
- repeticao inteligente
- comparativos de evolucao
- historico de desempenho

Tom correto:

- serio
- cientifico o suficiente para gerar confianca
- ainda prazeroso
- sem prometer milagres

### 3.9 Regras comerciais

Recomendacao:

- `Teste seu QI` base totalmente gratis
- `Turbinar QI` como premium
- leitura inicial forte e gratuita
- treino continuo, laboratorios extras e historico como premium

## 4. Modulo futuro - Teste vocacional

### 4.1 Missao

Criar um teste vocacional altamente agradavel de fazer, com cara de descoberta pessoal, nao de formulario burocratico.

Deve ser:

- totalmente gratis no teste base
- gamificado com maturidade
- gostoso de percorrer
- util de verdade

### 4.2 Estrutura do produto

Fluxo principal:

1. entrada do modulo
2. introducao curta
3. sequencia de telas gamificadas
4. leitura final de perfil
5. trilhas de carreira sugeridas
6. ponte premium opcional

### 4.3 Tipos de tela recomendados

Para fugir do formulario comum, o teste deve variar os formatos:

- escolha entre cenarios
- preferencia por ambientes
- preferencia por rotina
- desafios de perfil
- reacoes a situacoes
- ordenacao de prioridades
- pares de escolha
- microdecisoes com feedback visual

### 4.4 Resultado final

O teste deve devolver:

- perfil dominante
- combinacoes secundarias
- areas de afinidade
- ambientes em que a pessoa tende a render melhor
- alertas de desalinhamento
- sugestoes de trilhas e carreiras

### 4.5 Ponte para premium

No final, o premium nao deve vender apenas um texto maior.

Ele deve vender aprofundamento real.

Direcao recomendada:

- `Aprofundar meu perfil`
- `Plano premium de direcao profissional`
- `Laboratorio de carreira`

O premium futuro pode incluir:

- trilhas de profissao
- mapa de habilidades
- comparacao entre areas
- plano de desenvolvimento
- recomendacao de estudo
- ponte com `Premium Study`

### 4.6 Regra comercial

Recomendacao:

- teste base gratis
- resultado base gratis
- aprofundamento, trilhas e orientacao premium depois

## 5. Regras comuns aos dois projetos

### 5.1 Nao copiar app generico

Os dois modulos precisam parecer produtos proprios do `Study OS`, nao paginas prontas ou quiz de template.

### 5.2 Uma acao por tela

Regra:

```txt
cada tela conduz uma decisao, um desafio ou uma resposta principal
```

### 5.3 Recompensa visual forte

Usar:

- progressao visivel
- preenchimento elegante
- estados de conclusao
- resultados com peso visual

Evitar:

- poluicao
- textos longos demais
- excesso de caixas iguais
- tom infantilizado

### 5.4 Mobile first com cara premium

Os dois precisam nascer bem em:

- celular
- tablet
- desktop

Sem telas quebradas, sem dependencia de hover e sem excesso de peso.

### 5.5 Premium com valor real

Regra:

```txt
o gratis precisa ser bom de verdade
o premium precisa entregar continuidade, profundidade e evolucao
```
